БЛОКНОТ — офлайн-приложение (PWA)

1. Выложите папку в интернет (бесплатно, 1 минута): откройте https://app.netlify.com/drop и перетащите сюда эту папку целиком. Вы получите адрес вида https://что-то.netlify.app
2. Откройте адрес на телефоне ОДИН РАЗ с интернетом:
   Android (Chrome): меню ⋮ → «Установить приложение».
   iPhone (Safari): «Поделиться» → «На экран Домой».
3. Дальше приложение работает без интернета.
4. Синхронизация: ⚙ в приложении → токен GitHub (github.com/settings/tokens, право только «gist»). Один и тот же токен введите на всех устройствах.
5. Распознавание сканов: ⚙ → ключ Anthropic API (console.anthropic.com). Нужен интернет.
