NOTATNIK / БЛОКНОТ — офлайн-приложение (PWA), версия с выбором языка

Языки: polski (по умолчанию), українська, русский, English.
Смена языка: значок ⚙ вверху → «Język / Мова / Язык / Language».

ОБНОВЛЕНИЕ НА GITHUB
1. Распакуйте архив.
2. Откройте репозиторий → Add file → Upload files.
3. Загрузите ВСЕ файлы из архива (index.html, sw.js, manifest.webmanifest, иконки, README.txt).
   Файлы с теми же именами заменятся.
4. Commit changes. Через 1–2 минуты GitHub Pages выложит новую версию.
5. На телефоне полностью закройте приложение и откройте снова (иногда нужно открыть дважды).
   Заметки при обновлении не удаляются.
